# Bundled Arduino libraries

`ArduboyG/` – greyscale for the Arduboy by Peter Brown (tiberiusbrown),
MIT licence (`ArduboyG/LICENSE`). Taken over unmodified from
[ArduGray_Demo](https://github.com/tiberiusbrown/ArduGray_Demo), commit
c198193c439d3f0e94089206ac39ef39180ae7fe; there is no separate repository and
no entry in the Library Manager. The Makefile passes the directory
to arduino-cli with `--library`.
